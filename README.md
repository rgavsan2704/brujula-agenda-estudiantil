# Agenda+ · Agenda estudiantil

Web: https://rgavsan2704.github.io/brujula-agenda-estudiantil/

Agenda en español adaptable a móvil y ordenador. Incluye tareas, exámenes, prioridades, búsqueda y filtros, calendario mensual, horario con detección de solapamientos, asignaturas, notas, calificaciones ponderadas, temporizador de estudio, tema oscuro y copias JSON.

Los datos se guardan en el navegador de cada visitante (localStorage). No hay cuentas, sincronización entre dispositivos ni notificaciones push con la página cerrada. Exporta copias desde Ajustes. El temporizador necesita mantener la página abierta. El modo offline se activa después de la primera visita completa.

HTML, CSS y JavaScript sin compilación. GitHub Pages publica la rama main desde su raíz. No se incluyen datos personales ni claves.
